# THWS Chat (Frontend)

Minimalistisches, produktionsreifes Chat-Frontend für den THWS-ChatBot. Stack: **React 18 + TypeScript + Vite + Tailwind** (optional Headless UI für Quellen-Accordion). Keine Persistenz – Verlauf lebt nur im Speicher.

## Setup

```bash
npm i
cp .env.example .env   # ggf. API-URL anpassen
npm run dev
